ECN — Map User Guide

Everything you need to get started with the free ECN Gym Map

🗺️ Getting Started

The ECN Gym Map is a free resource showing climbing facilities across the UK, Ireland and Europe. All 343 mapped sites are shown as orange dots. Pan and zoom using your mouse or trackpad — on mobile, use touch gestures.

💡 Click any orange marker to open that gym's profile. Search by name using the search bar in the header.

🏟️ Gym Profiles

Click any marker to open the gym's profile panel. Each listing shows the gym's name, address, entry price, website, phone number, and confirmed amenities — bouldering, ropes, café, training boards, kids zone and more.

The Public Transport Nearby section shows the number of stops within 600m, pulled live from OpenStreetMap.

💡 If a gym belongs to a chain, a badge appears in the panel — click Show all locations to highlight every site in that group on the map.

🔎 Search & Filter

Use the search bar in the header to find a gym by name. Results appear as you type — click any result to fly to that gym and open its profile.

The filter bar below the header lets you narrow the map to gyms with specific features: bouldering, ropes, autobelay, café, Moonboard, Kilter, Tension, Woody, kids zone, or speed wall.

➕ Add a Missing Gym

Know of a facility that isn't on the map? Click + Add Gym in the header to submit it. Provide as much detail as you can — name, address, website, type and amenities. All submissions are reviewed by the ECN team before appearing on the map.

💡 The more detail you provide, the faster we can verify and add the listing.

✏️ Suggest a Correction

If a gym's information is outdated or incorrect, open the profile and click the Update Info tab. You can submit corrections for the name, address, website, entry price, or report a permanent closure. All submissions are reviewed before any changes are made.

📊 ECN Pro

This is the free version of the ECN map. ECN Pro adds population density and demographic overlays, adjustable walk/cycle/drive catchment analysis with population counts, competitor gym counts within any catchment zone, and location analysis for any point in Europe.
